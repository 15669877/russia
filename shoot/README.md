# 极简 C 语言打飞机（纯终端）

无任何 UI 装饰，只有字符画精灵 + 字符画边框。所有功能模块都已真实实现：
移动、射击、碰撞、敌机波次、爆炸动画、道具掉落、炸弹清屏、命数、计分、难度递增、游戏结束。

**全部代码为纯 C，无 Python 依赖。**

本项目按 **「种子派生模式」** 建成（见 `D:/俄罗斯/.workbuddy/SEED_DERIVATION_MODE.md`）：
素材只写标准姿态，其余派生形态由程序算出；数值型事实统一收进生成器产出的属性表；
判定逻辑只有一份，被游戏 / 自测 / 模拟器三方共用。

## 六、五个关键设计点

### 1. 素材只写一份，其余由程序派生

`gen_entities.c` 里只手写了每种精灵的**标准姿态**：

```
玩家机   "  ^  " / " /|\ " / "/___\"     3 行
小飞机   "ooooo" / "o___o"               2 行
```

其余形态全部算出来：

| 派生形态 | 怎么来的 | 为什么不能手写 |
|---|---|---|
| 镜像 `VAR_MIRROR` | 每行字符串左右反转 | 手写第二份必然和原图对不上 |
| 受损 `VAR_HURT` | `(行+列)%3==0` 的实心格换成 `*` | 手写两份容易画成一样 |
| 爆炸 3 帧 | 按曼哈顿距离收缩的菱形 | 手写三帧容易第 3 帧比第 2 帧还大 |

生成器还有一道**转义往返自检**：素材里的 `\` 写进 C 字符串必须转义，
写出去再解回来比对，不一致就**拒绝写文件**。
（这题里 `/___\` 这个反斜杠就是被它抓出来的 —— 没转义的话整份头文件编译不过。）

### 2. 数值型事实也收进生成器

血量、速度、分值、是否开火、横向漂移 —— 全在 `entities.h` 的属性表里，
游戏代码**只查表，不记数值**。

分值尤其重要：它由**精灵类型唯一决定**，而不是靠创建者记得去填字段。
（自测里专门有一条断言守着这点：手工造一架敌机再打死，必须正好得 100 分。）

### 3. 波次表是算出来的，不是手填的

20 波的难度曲线由公式生成，自检强制四条单调性：

- 敌机总数不减少
- 血量倍率严格递增
- 速度倍率不递减
- 出怪间隔不增加

第 5 波出 BOSS。`step5_wave.c` 演示了怎么用这张表出怪。

### 4. 碰撞是逐实心格判定的

精灵 art 里**空格 = 透明**，那一格不算实体。于是：

- 子弹擦着道具的透明角飞过去 → **不算命中**
- 子弹打在道具中心 → 算命中

`spr_overlap()` 先用包围盒快速排除，再逐格比对。
这是「精灵美术直接决定碰撞形状」带来的好处 —— 改美术就改了碰撞，不用改代码。

### 5. 逻辑只有一份

`game.h` 里的 `game_update()` / `game_fire()` / `game_kill_enemy()` 等函数，
被 `shoot.c`、`selftest.c`、`sim.c` **共用**。

所以自测测的就是游戏真正在跑的代码，模拟器跑的就是同一套逻辑，
不会出现「游戏改了、测试没改」的漂移。

## 七、显示端：为什么画面不闪（render.h）

与俄罗斯方块项目同源，解决三个终端游戏的通病：

| 症状 | 原因 | 解决 |
|---|---|---|
| 画面一闪一闪 | 每帧 `printf("\033[H\033[2J")` 整屏清掉再重画 | **增量渲染**：缓存每行内容，每帧只输出「和上一帧不同」的行 |
| 画面整体往上飘 | 打印行数超过终端高度，终端自动滚动 | **备用屏幕缓冲区**（`\033[?1049h`）：退出时原样恢复用户窗口 |
| 光标在画面里闪 | 光标停在画面上 | 游戏期间 `\033[?25l` 隐藏，退出时 `\033[?25h` 放回 |

另外两处细节：

- **战场高度自适应窗口**：`key.h` 里的 `term_rows()` 拿终端高度，`GH = rows - 7`，
  保证打印行数永远小于窗口高度，从根上杜绝滚动。
- **字符画布模型**：打飞机的精灵宽度不等（5~11 字符），所以不能像方块那样
  「一格占 2 字符」。这里改成字符画布：游戏逻辑往 `r_canvas[row][col]` 里盖字符，
  每帧清空重建，再逐行交给 `r_line()` 输出。

`render.h` 用法只有五个函数：

```c
r_enter();                              /* 游戏开始：进备用屏 + 藏光标 */
r_canvas_clear();                       /* 每帧开头：清空画布 */
r_canvas_stamp(row, col, art, n);       /* 往画布盖一个精灵 */
r_frame_start();                        /* 每帧开头 */
r_line(row, "内容");                    /* 写第 N 行（0 起算），没变就不输出 */
r_leave();                              /* 游戏结束：恢复光标 + 切回原屏 */
```
